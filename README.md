# VoteGuard

## Design and Development of a Hybrid Algorand DApp for Secure Voting and Result Verification

VoteGuard is a university coursework project that combines blockchain voting with a modern web dashboard.

## Planned Features

- Create elections
- Cast votes securely
- Verify results
- Blockchain transaction logging
- Admin dashboard
- Transparent result summary

## Technologies

- React
- Vite
- TypeScript
- Node.js
- Express
- Algorand LocalNet
- ESLint
- Prettier
- GitHub
